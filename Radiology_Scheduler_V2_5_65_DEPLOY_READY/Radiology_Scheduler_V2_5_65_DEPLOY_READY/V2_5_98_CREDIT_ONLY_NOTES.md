# V2.5.98 — position-based backups + credit-only cover

- Retired generic weekend backup scope. Backup eligibility follows the covered position.
- SPS RO and SPS UG are mandatory backup positions on any day/block.
- Centro UG 120 AM and Onko RO FULL remain mandatory; CENTRO RO is best-effort.
- Completed cover creates one rest credit for the coverer only. No work debt is created for the covered resident and no credit is consumed from them.
- Automatic backup ranking no longer uses work-debt age/priority.
- UI/Manual/Senior guide no longer present a backup work-debt model.
